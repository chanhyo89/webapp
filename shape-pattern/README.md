# 모양 규칙 찾기

발달장애 학생(초등 저학년)이 교사·보호자와 함께 모양 규칙을 보고 **? 에 들어갈 모양**을 고르는 반복연습 웹앱입니다.

`index.html` 파일 하나로 동작합니다. 브라우저에서 바로 열면 됩니다. 설치할 것은 없습니다.

## 설계 기준

| 항목 | 선택 |
|---|---|
| 학습 목표 영역 | 기초 수 개념 (패턴·규칙) |
| 대상 | 초등 저학년 |
| 인지 수준 | 말하기 약 2~3세, 듣기 약 2~3세, 생활기능 실제 연령의 약 30~50% |
| 앱의 성격 | 반복연습형 |
| 사용 맥락 | 협력형 (교사·보호자와 함께) |
| 오류 처리 | 한 번 더 기회 |
| 세션 길이 | 3문제 |
| 보상 | 별 스티커 + 칭찬 소리(기본 꺼짐) |
| 기기 | PC (마우스, 키보드 Tab 사용 가능) |

## 규칙

시작 화면에서 함께 하는 분이 규칙을 고릅니다.

| 규칙 | 예시 | 칸 수 |
|---|---|---|
| AB | ●■ ‖ ●■ ‖ ●■ ‖ ●**?** | 8 |
| AABB | ●●■■ ‖ ●●■■ ‖ ●**?**■■ | 12 |
| ABB | ●■■ ‖ ●■■ ‖ ●**?**■ | 9 |
| 섞기 | AB → AABB → ABB 한 문제씩 | |

- 규칙 묶음은 잘리지 않고 끝까지 다 보입니다. 묶음 사이는 조금 띄웁니다.
- ? 는 마지막 묶음 안의 한 칸(처음·중간·끝 중 무작위)에 나옵니다.
- 모양은 동그라미(빨강)·네모(파랑)·세모(노랑) 3가지이고, 문제마다 다른 모양 짝이 나옵니다.

## 한 문제의 흐름

1. "지금 할 일: ? 에 들어갈 모양을 골라요."
2. **모양 읽기**: 모양을 왼쪽부터 하나씩 강조하고, 소리가 켜져 있으면 이름을 읽습니다.
3. 틀리면: 고른 모양이 흐려지고, 앞 묶음에서 같은 자리의 모양이 강조됩니다. "이 모양을 봐요. 다시 골라요."
4. 맞으면: "맞아요! 여기는 네모." 별 하나가 채워집니다.
5. **다음 문제** 버튼을 눌러야 넘어갑니다.

끝 화면에 문제별 기록(규칙, 모양 줄, 정답, 처음에 맞힘/다시 골라서 맞힘)이 나옵니다. 기록은 페이지를 닫으면 사라집니다.
